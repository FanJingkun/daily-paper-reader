## 摘要
在多智能体强化学习（MARL）中，智能体间的通信在部分可观测条件下是提升性能的有效手段。基于表示学习的方法使去中心化智能体能够学习基于自身观测的消息，但这些方法仅依赖当前观测，无法传递随时间累积的信息。我们提出了Dreamer-CPC，一种去中心化的基于模型的MARL方法，将基于集体预测编码（CPC）的消息学习集成到DreamerV3的世界模型中。每个智能体独立维护一个世界模型和一个消息模块，并从世界模型的潜在状态中推断和交换消息，这些潜在状态反映了过去观测和动作的历史。我们在两个环境中评估了Dreamer-CPC：Observer（一个非合作的信息共享任务）和CatchApple（一个新引入的任务，其中与任务相关的观测会暂时缺失）。在两个环境中，Dreamer-CPC均优于IPPO-CPC（一种基于当前观测生成消息的现有CPC方法）以及无通信基线。特别是在CatchApple中，Dreamer-CPC获得的回合回报是IPPO-CPC的4至5倍，展示了在其他方法因观测缺失而失效的情况下有效的协调能力。这些结果表明，当仅凭当前观测不足时，基于世界模型潜在动态的通信可以支持去中心化决策。

## Abstract
In multi-agent reinforcement learning (MARL), inter-agent communication is effective for improving performance under partial observability. Representation learning-based approaches enable decentralized agents to learn messages grounded in their own observations, but they rely only on current observations and cannot convey information accumulated over time. We propose Dreamer-CPC, a decentralized model-based MARL method that integrates message learning based on Collective Predictive Coding (CPC) into the world model of DreamerV3. Each agent independently maintains a world model and a message module, and infers and exchanges messages from the latent states of the world model that reflect the history of past observations and actions. We evaluated Dreamer-CPC in two environments: Observer, a non-cooperative information-sharing task, and CatchApple, a newly introduced task in which task-relevant observations are temporarily missing. In both environments, Dreamer-CPC outperformed IPPO-CPC, an existing CPC-based method that generates messages from current observations, as well as no-communication baselines. In particular, in CatchApple, Dreamer-CPC achieved 4 to 5 times the episode return of IPPO-CPC, demonstrating effective coordination where other methods fail due to missing observations. These results suggest that communication grounded in the latent dynamics of world models can support decentralized decision-making when current observations alone are insufficient.

## 论文提出的方法论

**核心思想**
- 每个智能体 k 独立维护一个基于 RSSM 的世界模型和一个循环消息模块，二者以统一的目标函数联合优化。
- 消息的生成不依赖当前观测，而是从包含历史信息的 RSSM 潜在状态（hₖₜ, zₖₜ）和消息循环状态 ξₖₜ 中推断，从而传递随时间累积的信息。

**关键技术细节**
1. **RSSM 世界模型（沿用 DreamerV3）**
   - 确定性循环状态：hₖₜ = f_φₖ(hₖₜ₋₁, zₖₜ₋₁, aₖₜ₋₁, m̂ₜ)（m̂ₜ 为联合预测消息）
   - 随机先验：ẑₖₜ ∼ p_φₖ(·|hₖₜ)
   - 随机后验：zₖₜ ∼ q_φₖ(·|hₖₜ, xₖₜ)
   - 解码预测：x̂ₖₜ ∼ p_φₖ(·|hₖₜ, zₖₜ, mₜ)、r̂ₖₜ、ĉₖₜ
   - 消息注入两处：循环状态转移（使用预测消息 m̂ₜ）和观测解码（使用推断消息 mₜ）

2. **消息模块**
   - 循环消息状态：ξₖₜ = g_ψₖ(ξₖₜ₋₁, mₜ₋₁)
   - 消息先验：m̂ₖₜ ∼ p_ψₖ(·|ξₖₜ)
   - 消息后验：mₖₜ ∼ q_ψₖ(·|ξₖₜ, hₖₜ, zₖₜ)

3. **去中心化学习**
   - 对其他智能体产生的消息施加 **stop gradient**，避免梯度跨智能体传播，实现 DTDE（分散训练、分散执行）下的独立学习。

4. **统一变分下界**
   - 以预测目标 yₖₜ = (xₖₜ, rₖₜ, cₜ) 的边际对数似然为出发点，用 Jensen 不等式推导变分下界 Eₖ，由三部分组成：预测对数似然、潜在状态 KL、消息 KL。
   - 实践中使用 KL-balanced 损失和 free bits（β_pred = β_dyn = 1，β_rep = 0.1，β_m-dyn = 1×10⁻³，β_m-rep = 1×10⁻⁴），同时优化世界模型消息联合损失 L_wm-msg。

5. **Actor-Critic 想象学习**
   - 遵循 DreamerV3 的 actor-critic 程序，但想象轨迹中**同步加入跨智能体消息交换**：每个想象步用消息先验生成消息、交换后用 Rssm 状态转移，最终在包含通信的想象 rollout 上计算 actor/critic 损失。

**算法流程说明**
- 训练分两阶段：① 世界模型与消息模块学习（从回放缓冲采样轨迹，按先验/后验/解码步骤更新模型参数）；② Actor-Critic 学习（在想象的潜在轨迹中，结合消息交换步骤进行策略和值函数更新）。

## 实验设计

**基准环境（均为论文自建）**
1. **Observer**
   - 两个智能体：Agent 1 固定不动，观测 16 维 one-hot 表示奖励位置，没有实际动作（仅 no-op），无奖励。
   - Agent 2 在 4×4 网格上移动，观测自身位置（one-hot），无法直接看到奖励位置；动作集为 {上下左右、停留、挖掘}，挖掘到正确位置得 +1，其他动作 -0.01。
   - 评估 Agent 2 的回合回报，固定 horizon H=200。
   - 特点：任意时刻聚合所有观测即可完全重建全局状态，但奖励不共享。

2. **CatchApple（新引入）**
   - 8×8 下落物体区域 + 地面行（8 列）。
   - Agent 1 固定，观测物体轨迹（65 维 one-hot，含遮挡标志），无奖励，仅 no-op。
   - Agent 2 控制地面行接物者，观测自身列和物体列或遮挡标志，动作集为 {still, left, right}。
   - 物体初始列、轨迹类型（垂直/左斜/右斜）随机，到达底部时若与 Agent 2 列匹配则 +1，其余时间 -0.01；固定 horizon H=500。
   - 关键：物体在遮挡行时，所有智能体的观测均缺失物体位置，**必须基于历史预测落点**，这是体现 Dreamer-CPC 优势的核心场景。

**对比方法**
- IPPO-CPC（现有 CPC 消息学习 + IPPO，基于当前观测生成消息）
- IPPO（无通信）
- 独立 DreamerV3（no-comm，无消息通道）
- DreamerV3 + 共享观测（obs-shared，上界参考）
- Dreamer-CPC 使用两种消息通道：20×1（单一 20-way one-hot）和 5×4（四个独立 5-way one-hot）

**实现细节**
- 每个智能体的 RSSM 和 actor-critic 约 3M 参数，架构基于 DreamerV3。
- 消息模块采用 BlockGRU（hidden=64, blocks=8），消息先验/后验为 2 层 MLP（hidden=128，GELU 激活）。

**实验规模**
- 每个环境各 10 个独立 seed，报告 IQM（四分位均值）和 95% 置信区间（2,000 次 bootstrap）。

## 主要结论与发现

1. **Observer 环境**
   - obs-shared（上界）IQM = 53.63。
   - Dreamer-CPC 5×4 消息最优：IQM = 39.85（95% CI [34.22, 40.82]）；20×1 消息：19.72。
   - IPPO-CPC 仅 7.31（20×1）和 6.81（5×4）；IPPO 与 no-comm 接近 0（1.74 与 0.48）。
   - 结论：在非合作、不共享奖励、观测严重受限时，基于世界模型潜在状态的通信显著优于基于当前观测的通信。

2. **CatchApple 环境**
   - obs-shared 最优 IQM = 38.21；Dreamer-CPC 5×4 达到 28.53（95% CI [23.87, 31.56]），20×1 达到 20.47。
   - IPPO-CPC 仅为 5.52（5×4）和 4.98（20×1），接近无通信基线（IPPO 4.66、no-comm 5.93）。
   - **Dreamer-CPC 回报为 IPPO-CPC 的 4～5 倍**，表明观测暂时缺失时，仅基于当前观测生成消息的方法完全失效，而世界模型的历史累积信息能支撑预测性协调。

3. **总体结论**
   - 基于 RSSM 潜在动态的通信，在未来观测不足或需要预测的场景中，能有效支持去中心化决策。
   - 通讯消息学习与世界模型学习可以在统一变分目标下联合优化，性能优于已有方法。

## 优点

- **理论动机清晰**：以 CPC 的变分贝叶斯框架为基石，将消息学习纳入世界模型的联合生成模型，推导出可优化的变分下界。
- **框架合理**：统一目标函数联合优化 RSSM 与消息模块；收消息使用 stop gradient，实现真正的去中心化（DTDE）学习，不引入跨智能体梯度。
- **设计针对性强**：消息从反映历史的潜在状态生成（而非仅当前观测），精准对应当前观测不足的任务需求；消息同时注入状态转移与观测解码，兼顾预测与重建功能。
- **想象阶段引入通信**：在 DreamerV3 的想象 rollout 中同步进行消息交换，使策略优化在模型空间中即可学习使用通信，工程实现完整。
- **实验统计规范**：使用 IQM 与 bootstrap 置信区间，降低离群种子的影响。
- **环境设计契合目标**：CatchApple 的临时遮挡设置直接区分了“基于当前观测的通信”与“基于历史推断的通信”的差异，具有很好的区分度和说服力。

## 不足与局限

- **计算资源与训练细节缺失**：未报告 GPU 类型、训练时长、环境采样步数、消息模块参数量等关键复现信息，复现难度较高。
