## 摘要
人工智能代理预计在未来决策系统中发挥越来越重要的作用。在本文中，我们考虑由异构多智能体系统（MAS）组成的协作系统，其中成员具有不同的能力和运营成本。我们研究智能体如何相互委托任务，以便在资源受限的场景下有效完成某些研究任务。我们首先开发了一种基于多智能体强化学习（MARL）的委托训练方法，使智能体能够做出顺序委托决策，同时最小化总执行成本。然后，我们将该方法扩展到具有规定委托拓扑的MARL。此外，我们引入了两个用于多智能体系统中协作与委托的新框架。第一个框架提出，智能体的策略不仅依赖于底层马尔可夫决策过程的当前状态，还依赖于交互历史，包括之前的联合行动。这种依赖历史的表述即使在完全可观测的环境中也能改善协调，而在这种环境中，传统MARL方法通常限制策略仅依赖于当前状态。第二个框架提出了一种新颖的、可能多维的货币机制，以促进MAS的协作与委托。

## Abstract
AI agents are expected to play an increasingly important role in future decision-making systems. In this paper, we consider collaborative systems composed of heterogeneous multi-agent systems (MAS), where their members have different capabilities and operating costs. We study how agents can delegate tasks to one another so that certain research tasks can be completed effectively under resource-constrained scenarios. We first develop a multi-agent reinforcement learning-based (MARL) delegation training that enables agents to make sequential delegation decisions while minimizing the total execution cost. We then extend this approach to MARL with prescribed delegation topologies. Furthermore, we introduce two new frameworks for collaboration and delegation in multi-agent systems. The first framework proposes that an agent's policy depends not only on the current state of the underlying Markov decision process but also on the interaction history, including previous joint actions. This history-dependent formulation can improve coordination even in fully observable environments, where conventional MARL methods typically restrict policies to depend only on the current state. The second framework proposes a novel, potentially multi-dimensional monetary mechanism to facilitate the collaboration and delegation for MAS.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在由异构多智能体系统（MAS）组成的协作环境中，如何设计有效的任务委托（delegation）机制，使具有不同能力、所有权关系和运营成本的智能体在资源受限条件下以最低总成本完成任务。
- **背景动机**：
  - 大型语言模型（LLM）驱动的 AI 智能体日益复杂，但调用 API 模型可能产生高昂且不可预测的令牌成本；小型/廉价模型足以处理常规任务，只有困难任务才需要更强的模型。
  - 现有工作（如 FrugalGPT、RouteLLM、AutoMix、MAGRPO、CoLLM 等）侧重于集中式路由或优化智能体的语言生成策略，而非将"委托"本身作为智能体显式博弈行为来建模。
  - 传统 MARL 方法在完全可观测环境中通常仅依赖当前状态（Markov 策略），忽略了历史交互在支持互惠、信任和跨期激励中的战略价值。
- **整体含义**：本文提出在具备预训练任务策略的智能体之上学习一个"委托层"（meta-policy），回答"谁应执行""谁可委托给谁""执行决策如何依赖成本和历史交互"等问题，为异构多智能体协作提供更高效、更通用的委派与协调范式。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **整体框架**：将任务委托建模为协作马尔可夫博弈（Markov Game），在预训练策略之上学习联合委托策略 π，目标函数为最大化折扣累计协作奖励：
  - J(π) = E[ Σ γ^(t-1) Σ R_i(s_t, a_t) ]
  - 每步奖励 R_i 由环境奖励 Ṝ 与个体执行/委托成本 C_i 构成：R_i = αṜ − βC_i

- **三种委托结构**：
  - **管理约束（Management Constraints）**：层级化单向控制关系（A→B→C），每个时间步只有一个智能体实际执行；动作空间扩展为 A_i ∪ D_i ∪ {no-op}；执行规则遵循严格层级链。
  - **委托约束（Delegation Constraints）**：通过有向图表示任意智能体间可交互委托（任何智能体可委托任何其他智能体）；允许多个智能体同时执行；执行条件为"当且仅当被他人委托且不向他人委托时"才执行；每个回合由 oracle 选择非空 kickoff 子集。
  - **货币交易（Transferable Money）**：智能体可通过虚拟货币激励他人接受委托。

- **历史依赖策略（History-dependent Policy）**：
  - 策略 π_it 映射公共历史 h_t = (x₁,a₁,…,x_{t−1},a_{t−1},x_t) 到动作空间，而非仅当前状态。
  - 关键优势：支持奖励、惩罚、互惠等跨期激励，传统 Markov 策略是其特例。
  - 动机示例表明，历史依赖策略下可实现帕累托改进的均衡（A 的收益 8.9 vs Markov 策略下 0），证明历史信息在完全可观测环境中的战略价值。

- **两步 Nash 值迭代算法（Algorithm 1）**：
  - 枚举所有两步历史，构造每步的正常形式博弈，计算纯策略 Nash 均衡集。
  - 枚举所有确定性延续选择器 σ₂，对每个 σ₂ 计算 t=1 诱导博弈的均衡，构建候选策略组合。
  - 选择最大化目标 agent（如 B）价值的均衡策略。
  - **定理1**：在有限两步动态博弈满足子博弈存在纯策略 Nash 均衡的条件下，算法1返回纯策略子博弈完美 Nash 均衡。可通过反向归纳扩展到 n 步博弈。

- **货币转移机制细节**：
  - 每个智能体拥有货币余额 w_i，增广状态为 s̃_it = (s_t, w_it)；货币可多维。
  - 转移动作 p_ijt 由合同 Cᵢ: A → Rⁿ⁻¹ 决定，即按联合行动（而非仅接收者个体动作）支付。
  - 货币是内部媒介，不直接进入环境奖励；余额不足时联合行动不可行。
  - 与声誉类方法（DRIVE、LIO 等）的区别：货币不是 reward-shaping 信号，而是可转移且有预算约束的余额记录。

### 6. 主要结论与发现

- **管理约束（层级结构）**：训练出的 DQN 协调器达到 return 27.56 ±0.32、准确率 0.982、成本 $0.033/episode，相对 always-Ultra（return 23.90、成本 $0.063）约 +3.7 return、成本减半；1000 episodes 累计成本从 $60.8 降至 $31.1。
- **委托约束（图结构）**：图协调器达到 return 25.20 ±0.42、成本 $0.043/episode，优于 always-Ultra（return 23.31、成本 $0.068），但对管理协调器（return 28.70、成本 $0.024）仍有差距；图策略更频繁调用 C、允许多 agent 并行，解释了略低的 return 和 accuracy。
- **历史依赖策略**：证明历史依赖策略是 Markov 策略的严格超集，可支持互惠机制实现更高收益的均衡（示例中 A 从 0 提升至 8.9）；Algorithm 1 可有效找到确定性历史依赖 Nash 均衡。
- **货币转移机制**：仅使用 IQL 时两个 agent 均拒绝协作（episodic return 0）；加入货币转移后，agent 学会有偿帮助对方，实现完全协作（episodic return 990），证明货币框架能有效激励协作行为。

### 7. 优点

- **问题定义新颖**：将"委托"显式建模为多智能体顺序决策问题（而不是集中式路由），引入管理约束/委托约束/货币交易三级结构，层次清晰、贴近现实组织。
- **历史依赖策略的理论贡献**：严格论证在完全可观测环境中历史信息对互惠和协调的战略价值，并提供可证明的 Nash 均衡求解算法（Algorithm 1 + 定理 1）。
- **货币转移机制设计巧妙**：货币与环境奖励解耦、按联合行动定价、余额不足时不可行——既避免了奖励可转移性的假设，又为大规模分布式 MARL 中的协作激励提供了可扩展方案。
- **工程可复现性强**：离线缓存求解器答案与标注、统一种子管理、明确记录超参数（附录 D），20 seeds 统计显著检验提升了结果可信度。

### 8. 不足与局限

- **实验覆盖面窄**：仅 GSM8K 单基准；货币转移只在小型人工博弈中验证，未在真实 LLM 任务上证明可扩展性。
- **理论局限**：定理 1 仅覆盖有限两步博弈（扩展到 n 步依赖反向归纳，但计算复杂度可能爆炸）；算法需枚举所有延续选择器，实际应用中可能受限；未处理相关均衡/粗相关均衡。
- **历史依赖策略未端到端验证**：理论示例说明了价值提升，但在大规模 MARL 场景中，历史信息如何高效编码、状态空间如何控制尚待研究。
- **货币定价机制未完善**：作者在结论中坦承未解决基于历史的联合行动定价问题；合同（contract）的设定给定后学习才收敛，定价本身的最优性未讨论。
- **端到端可部署性**：管理策略训练后中间体 B 承担大部分任务，但若部署环境中模型能力变化（如新模型发布）或成本结构改变，需重新训练委托层；离线标注使用 Ultra 同时作为求解器和判题器，存在潜在的偏差风险（虽然手查 200 项全部一致）。
- **计算资源细节缺失**：未报告训练时长、GPU 数量总核算力，对于评估系统性成本上限不够透明。
